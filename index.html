🐾 画像と音声をひとつに

Combine Images and Audio into One Video

1枚の画像と音声ファイルから、MP4動画を作れる無料ツールです。イラストや写真にナレーション・BGM・ASMR音声などを付けて、YouTube・X・Instagram・TikTok に投稿できます。

使い方（3ステップ）

  1. 画像を選びます。
  2. 音声を選びます。
  3. 動画サイズを選んで「動画を作成する（MP4・高速）」を押します。

アカウント登録やインストールは不要です。このページを開くだけで使えます。

プライバシーについて：ファイルはアップロードされません。
変換はすべてお使いのブラウザの中で行います。画像や音声がサーバーに送られることはありません。タブを閉じれば、選んだファイルはブラウザから消えます。MP4の作成には、Chrome / Edge に内蔵の WebCodecs（ブラウザ標準のエンコーダー）と、mp4-muxer という小さなプログラム（インターネットから読み込み）を使います。初回の読み込みだけインターネット接続が必要です。このページは GitHub Pages で公開されています。ページを開くときに GitHub のサーバーにアクセスしますが、選んだ画像・音声が送られることはありません。

対応形式

  • 画像：JPG / PNG / WebP
  • 音声：MP3 / WAV / M4A / OGG / FLAC（96kHz など高いサンプルレートの音声も、自動で 48kHz に変換します）
  • 出力：MP4（H.264 + AAC）、10fps
  • 動画サイズ：画像と同じ縦横比。解像度は元のサイズ / 長い辺 2160px / 1920px / 1280px / 720px から選べます
  • 対応ブラウザ：Chrome / Edge（MP4作成には WebCodecs が必要です）

Firefox / Safari では MP4作成ができない場合があります。その場合は「WebMで作る」をお試しください（音声と同じ時間がかかります）。

MP4作成方式を確認しています…

動画の縦横比は、選んだ画像と同じになります。縦型画像は縦型のまま、横型画像は横型のままです。解像度は長い辺の長さで選びます。画像より大きい解像度を選んでも、画質は上がりません。無理に引き伸ばすと線がぼやけて画質が落ちるため、元のサイズを推奨します。

画像と音声を選ぶと、作成ボタンが使えます。

ログ：まだ変換していません。「動画を作成する」を押すと、ここに進み具合と経過時間が1行ずつ出ます。

⬇ 完成した動画をダウンロード（.mp4）

出力は最初から MP4（H.264 + AAC）です。静止画なので 10fps で作ります（動きはありませんが、YouTube / X / Instagram / TikTok に投稿できます）。完成した動画のファイル名は、選んだ音声ファイルと同じ名前になります（例：音声が sample.mp3 なら sample.mp4）。

よくある質問

Q. 無料ですか？
はい、無料です。回数制限やアカウント登録はありません。

Q. ファイルはどこに送られますか？
どこにも送られません。変換はブラウザの中でだけ行います。

Q. 音声が長いと時間がかかりますか？
はい、長さに応じてかかります。短い音声なら数秒〜数十秒で終わることが多いです。1時間の音声では数分かかることがあります。ただし再生しながら録画する方式ではないので、再生時間よりは短く終わります。

Q. 動画の画質はどうなりますか？
静止画のため、10fps で作成します。動きはありませんが、投稿用として問題なく再生できます。

Q. 長い音声（1時間など）も変換できますか？
はい。MP3で10分を超える音声は、ストリーミング方式で少しずつ変換します。静止画のため、長い動画では映像を 1〜2fps にして、変換時間とファイルサイズを抑えています。

Q. 大きい解像度を選ぶと画質は上がりますか？
いいえ、上がりません。元の画像より大きい解像度を選んでも、元の画像にない細かさは生まれません。無理に引き伸ばすと線がぼやけて画質が落ちるため、このツールでは引き伸ばさず、元のサイズを推奨します。

Q. 商用利用はできますか？
はい、このツール自体の利用は無料です。ただし、画像や音声の権利は、素材の権利者の条件に従ってください。

MP4が作れないときは、まずここを確認

1. このファイルをダウンロードして、Chrome / Edge で直接開く（WebCodecs は Chrome / Edge 用です。Firefox / Safari では MP4作成ボタンが使えないことがあります）。
2. ページを開き直して、上の黄色い診断欄を確認する。
3. それでもダメなら「WebMで作る」を使うか、下のコマンドで作る。

パソコンに ffmpeg が入っている場合（別ルート）

このツールが使えない場合は、パソコンに ffmpeg が入っていれば、同じ画像＋音声をコマンドで MP4 にもできます。ファイルは自分のパソコンから出ません。

  1. ffmpeg が入っているか確認する：ターミナル（Mac）またはコマンドプロンプト / PowerShell（Windows）を開いて、ffmpeg -version と入力して Enter を押します。バージョンが表示されれば入っています。表示されなければ、ffmpeg.org から入手するか、Mac の場合はターミナルで brew install ffmpeg を実行してください。
  2. 画像と音声を同じフォルダに入れる：画像のファイル名を image.jpg、音声のファイル名を audio.mp3 に変更します（日本語やスペースがあると、コマンドがうまく動かないことがあります）。
  3. そのフォルダでターミナルを開く：Windows はフォルダ内で Shift キーを押しながら右クリック →「PowerShell ウィンドウをここで開く」、Mac はフォルダを右クリック →「フォルダに新規ターミナル」です。またはターミナルで cd フォルダの場所 と入力して移動します。
  4. 下のコマンドを貼り付けて Enter を押す：「コマンドをコピー」ボタンでコピーできます。
  5. 完成を確認する：同じフォルダに output.mp4 ができます。これが完成した動画です。エラーが出た場合は、ファイル名が image.jpg / audio.mp3 になっているか、ffmpeg が入っているかをもう一度確認してください。
ffmpeg -loop 1 -i image.jpg -i audio.mp3 -c:v libx264 -tune stillimage -c:a aac -b:a 192k -pix_fmt yuv420p -shortest output.mp4
